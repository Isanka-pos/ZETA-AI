FAQ

Frequently Asked Questions

How do I copy my channel post link?
Open WhatsApp → go to your channel → open the post → tap the three dots (or Share) → Copy Link. The link looks like: https://whatsapp.com/channel/0029V…/1510 — the number at the end is the message ID.
How many reactions can I send?
You can send between 1 and 1000 reactions per launch using the slider. You can launch the engine multiple times if you need more.
Which emojis are supported?
All 7 official WhatsApp reaction emojis are built in (❤️ 👍 😂 🔥 😮 😢 🙏) and you can also type any custom emoji into the custom emoji box.
Why did the engine show an error?
The most common reasons: the link is not a valid channel post link (must end with a message number), the API server is temporarily busy, or the API key expired. Check your link format and try again in a few seconds — you can also open the API response directly to see the exact error message.
Is it really free and unlimited?
Yes! The tool is 100% free with no limits and no signups. Just keep the API server happy by not spamming thousands of requests per minute.
